# Trekka

##  Tema
Aplicação Móvel para Registo e Partilha de Trilhos

##  Descrição
Aplicação móvel que permite aos utilizadores registar trilhos de caminhada ou corrida utilizando o GPS do dispositivo. Durante a atividade, a aplicação recolhe automaticamente pontos de localização para desenhar o percurso realizado no mapa e calcular métricas como distância, duração e velocidade média.
